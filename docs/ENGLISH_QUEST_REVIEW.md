# English Quest 기획 검토서 (개발 전)

대상: 초등 영어 800단어 기준 영어 학습 모듈 (Daily Level Up 플랫폼 추가 기능)
상태: 검토 (아직 개발하지 않음)

---

## 1. 한 줄 결론

방향은 맞습니다. **학년과 실력을 분리하고, 6단계 레벨 + 자체 단어 DB** 구조는 좋습니다.
다만 개발 전에 아래 **필수 보완 7가지**(콘텐츠 출처, 외부 API 의존, 음성, 문제 형식, 진단 설계, 자동 난이도 기준, 데이터 구조)를 정해야 합니다.

---

## 2. 잘된 점

- **학년과 실력 분리**: 아이마다 학년과 영어 실력이 다르므로 맞는 설계입니다.
- **자체 단어 DB**: 외부 API에 매번 의존하지 않고, 검수된 단어만 쓰는 것이 아이 교육용으로 안전합니다.
- **진단 테스트 + 자동 조절**: 수동 선택만 하면 실력보다 기대에 맞춰 고르는 문제가 생깁니다.
- **"여러 번의 결과를 보고 바꾼다"는 원칙**: 한 번의 시험으로 레벨을 바꾸지 않는 점이 좋습니다.
- **기존 시스템 재사용 가능**: 수학에서 만든 보상 중복 방지, 회차 제한, 연속 학습 구조를 그대로 쓸 수 있습니다.

---

## 3. 필수 보완 사항 (개발 전에 결정)

### 3-1. 단어 목록의 출처와 검수 (가장 중요)
- 현재 기획서에는 **800단어 목록이 없습니다.** 예시 단어만 있습니다.
- 목록을 어디서 가져왔는지(교과서 어휘, 공개 어휘 목록, 직접 작성) 정해야 합니다. 출처마다 **이용 조건(저작권, 상업 이용, 재배포)** 이 다릅니다.
- 한국어 뜻과 예문은 **사람이 검수**해야 합니다. AI가 만든 초안을 그대로 쓰면 오역이나 아이에게 부적절한 예문이 섞일 수 있습니다.
- **제안**: 단어 목록 → 뜻·예문 → 검수 → 등록 순서의 콘텐츠 파이프라인을 먼저 만듭니다. 코드보다 콘텐츠가 먼저입니다.

### 3-2. 레벨별 단어 수와 구성
- 800단어를 6레벨에 나누면 평균 약 133개입니다. 기획서는 Lv.6(중학 입문)을 800단어에 포함할지 불명확합니다.
- **제안**: Lv.1~5 = 800단어(초등 범위), Lv.6은 별도 확장 콘텐츠로 분리합니다.
- 레벨 안에서도 난이도 차이가 큽니다. 수학처럼 **레벨 내 단계(예: 5단계)** 를 두면 진도가 더 촘촘해집니다.
- 예시 단어 배치 점검이 필요합니다. 예: `cloudy`(Lv.2)와 `sometimes`(Lv.3)의 난이도 기준을 교재 기준으로 통일해야 합니다.

### 3-3. Free Dictionary API 의존 여부
- 기획서는 "영어 뜻·품사·발음·사전 예문을 API로 가져온다"고 합니다.
- **확인 필요**: 검색으로 `freedictionaryapi.com`의 이용 조건과 엔드포인트를 확인하지 못했습니다. 비슷한 이름의 `api.dictionaryapi.dev`는 인증 없이 쓸 수 있다고 소개되어 있으나, 라이선스 조건은 찾지 못했습니다. ([publicapi.dev 소개](https://publicapi.dev/free-dictionary-api))
- **위험**
  - 아이 화면이 외부 서비스 장애에 영향을 받습니다.
  - 사전 예문이 아이에게 부적절할 수 있습니다.
  - 이용 조건이 상업·교육용 저장을 막을 수 있습니다.
- **제안**: 런타임에 실시간 호출하지 말고, **검수 과정에서 한 번 가져와 자체 DB에 저장**합니다. 저장 전 이용 조건을 반드시 확인합니다. (참고: 상용 사전 API는 저장과 표시에 별도 계약이 필요한 경우가 많습니다. [Merriam-Webster 이용 조건](https://dictionaryapi.com/info/terms-of-service))

### 3-4. 발음(음성)
- 초등 영어 학습에서 **듣기는 필수**입니다. 기획서에는 "발음 표기"만 있고 음성 방식이 없습니다.
- 선택지
  - (a) 브라우저 음성 합성(TTS): 구현이 빠르지만 기기마다 목소리가 다릅니다.
  - (b) 사람이 녹음한 오디오 파일: 품질이 가장 좋지만 제작 비용이 듭니다.
  - (c) 외부 TTS 서비스: 비용과 이용 조건을 확인해야 합니다.
- **제안**: 1차는 (a)로 시작하고, 핵심 단어(Lv.1~2)부터 (b)로 교체합니다.

### 3-5. 문제 형식 (기획서에 없음)
- 기획서에는 "퀴즈"만 있고 형식이 없습니다. 아이 연령에 맞는 형식을 정해야 합니다.
- **제안 (단계별)**
  1. 그림·단어 고르기 (4지선다, 초등 1~2학년)
  2. 듣고 고르기 (음성 → 단어)
  3. 뜻 고르기 (영어 → 한국어)
  4. 철자 맞추기 (글자 나열, 고학년)
  5. 빈칸 문장 고르기 (예문 활용)
- 그림은 Lv.1에 특히 중요합니다. 그림 소재(라이선스 포함)를 확보해야 합니다.

### 3-6. 진단 테스트 설계
- 기획서: 15~20개 단어로 진단.
- **보완 사항**
  - 문항 수가 적어서 **찍기(우연히 맞힘)** 영향이 큽니다. 4지선다라면 우연히 맞힐 확률이 25%입니다.
  - **적응형 방식**을 추천합니다. 맞히면 한 단계 올리고, 틀리면 낮춥니다. 같은 문항 수로도 더 정확하게 위치를 찾습니다.
  - 응답 시간은 참고만 합니다. 시간 압박을 주면 아이가 위축될 수 있으므로 **제한 시간을 두지 않습니다.**
  - 진단은 **처음 1회만** 하고, 결과를 보호자에게 보여준 뒤 시작 레벨을 승인받는 것을 제안합니다.

### 3-7. 자동 난이도 조절 기준
- 기획서 기준: 정답률 90% 이상 → 상향 후보, 60% 미만 → 복습 확대.
- **보완 사항**
  - **최소 시도 수가 필요합니다.** 2~3문제로 판단하면 우연에 흔들립니다. 예: 최근 20문항 이상.
  - **연속성 조건**: 예를 들어 "최근 3회 학습에서 2회 이상 90% 이상"처럼 여러 번의 결과를 봅니다. 기획서의 "한 번으로 바꾸지 않는다"는 원칙과 맞습니다.
  - **상향과 하향의 비대칭**: 하향(복습)은 쉽게, 상향은 신중하게 합니다.
  - 수학의 **연산별 진도**처럼 영어도 **단어 숙달도**(맞힌 횟수, 마지막으로 본 날)를 단어마다 기록하면, 복습 주기를 자동으로 잡을 수 있습니다.
  - 보호자 승인: 수학의 학년 승인과 같은 방식으로, 레벨 상향은 **보호자가 확인**하게 할지 결정합니다.

## 4. 추가로 검토할 사항

### 4-1. 아이 개인정보와 안전
- 외부 사전 API를 호출할 때 **아이 식별자(id, 이름, 기록)를 보내지 않습니다.** 단어만 보내야 합니다.
- 예문과 뜻은 검수를 거친 것만 노출합니다.
- 외부 링크(사전 사이트 등)는 아이 화면에 넣지 않습니다.

### 4-2. 하루 학습 시간 (기존 수학과의 관계)
- 수학은 하루 최대 5회차(40문제), 영어는 별도 기준이 필요합니다.
- **제안**: 하루 목표 30분을 수학과 영어가 나눠 쓰는지, 각각 따로 두는지 결정합니다.

### 4-3. 보상 설계
- 영어 정답 1개당 경험치·코인 기준을 정합니다. 수학 기준(정답 1개 = 5 XP)과 맞출지 결정합니다.
- 보상 중복 방지 규칙은 수학과 같은 방식으로 재사용합니다.

### 4-4. 보호자 화면
- 영어 학습 기록(단어별 정답률, 자주 틀린 단어)을 보호자가 볼 수 있어야 합니다. 이후 4단계의 보호자 화면과 함께 설계하는 것이 좋습니다.

### 4-5. 접근성
- 음성 재생 버튼은 터치 영역이 충분해야 합니다. 현재 키패드 기준(최소 64px)을 따릅니다.
- 영어 문장이 길어져도 레이아웃이 깨지지 않도록 기존 카드 설계를 유지합니다.

## 5. 제안 데이터 구조 (초안)

| 테이블 | 용도 | 주요 열 |
|---|---|---|
| `english_words` | 단어 DB (검수 완료본) | id, word, level(1~6), step, part_of_speech, meaning_ko, example_en, example_ko, audio_url, source, reviewed_by, reviewed_at |
| `english_progress` | 아이별 단어 기록 | child_id, word_id, correct_count, attempt_count, last_seen_at, next_review_at |
| `english_level_state` | 아이별 레벨 상태 | child_id, current_level, step, placement_done, level_up_approved |
| `english_attempts` | 퀴즈 기록 | child_id, word_id, question_type, is_correct, answered_at |

- `english_words`는 모든 아이가 읽을 수 있는 공개 데이터(검수본만)입니다.
- 나머지는 **본인 아이만 읽고 쓸 수 있도록** RLS를 적용합니다. 수학과 같은 방식입니다.
- 정답 판정은 수학처럼 **서버 함수**에서 합니다.

## 6. 개발 순서 (보완 반영)

1. **콘텐츠**: 800단어 목록, 출처·이용 조건 확인, 뜻·예문 검수 (코드 전 필수)
2. **DB**: 단어·진도·레벨 테이블과 RLS, 정답 판정 함수
3. **단어 학습 화면**: 레벨 선택, 4지선다 퀴즈 1종 (그림 없이 텍스트부터)
4. **음성**: TTS 적용 → 핵심 단어부터 녹음 파일로 교체
5. **진단 테스트**: 적응형 15~20문항, 보호자 확인 후 시작 레벨 적용
6. **자동 난이도 조절**: 최소 시도 수와 연속 조건 적용
7. **보호자 화면**: 영어 기록 요약

### 9-2. 출처 검토 (hanaabc)
- 게시글 내용: 교육부(2015년) 초등학생 필수 영단어 800개를 정리한 글입니다. 원형 800개 외에 변형 단어(동사·형용사·명사 불규칙 변형 등)가 포함되어 합계 약 1,126개입니다.
- 게시글 자체에 저작권 표시나 이용 허락 문구는 없습니다.
- 한글 뜻은 게시자가 붙인 것이므로, 그대로 쓰면 제3자 저작물이 됩니다.
- **판단**: 단어 목록의 원출처는 교육부 자료입니다. 원자료의 이용 조건(공공누리 등)을 확인하고, **한글 뜻과 예문은 우리가 새로 작성·검수**하는 것이 안전합니다.

### 9-3. Lv.6 포함과 출처 불일치 (결정 필요)
- 교육부 초등 필수 800단어에는 opportunity, esponsibility, communicate 같은 중학 수준 단어가 **없습니다.**
- 따라서 "800단어 + Lv.6 포함"을 그대로 하면 출처가 둘로 나뉩니다.
- **제안 A (추천)**: 800단어(교육부 자료) = Lv.1~5, Lv.6은 중학 입문 목록에서 별도로 100~150개를 추가합니다. 출처를 분리해서 관리합니다.
- **제안 B**: 800단어 전체를 6레벨로 재배치합니다. 교육부 목록 안에서 중학 수준 단어는 없으므로 Lv.6을 비워 두는 것이 됩니다.

### 9-4. 하루 30분 나누기 (결정 필요)
- 수학과 영어를 나누면, 학습 목표를 과목별로 둬야 합니다.
- **제안**: 수학 20분 + 영어 10분, 또는 수학 15분 + 영어 15분. 보호자가 정할 수 있게 설정으로 둡니다.
- 홈의 "오늘 학습 목표" 바도 과목별 두 줄로 나눕니다.

### 9-5. 사전 API 검토 결과
- **Free Dictionary API (freedictionaryapi.com)**
  - 데이터 출처: 영어 위키낱말사전(Wiktionary)이며, **CC BY-SA 4.0** 라이선스입니다. ([라이선스 원문](https://creativecommons.org/licenses/by-sa/4.0/))
  - 필요한 조건: 원문 링크 표기, 사이트 이름 표기, 파생물에도 같은 라이선스 적용(ShareAlike).
  - 호출 제한: API 키 없음, IP당 시간당 1,000회. 초과하면 429 응답.
  - 제공 항목: 뜻, 품사, 발음 표기, 예문. 음성 파일 항목은 없습니다.
- **판단**
  - 아이 교육 서비스에 쓰려면 ShareAlike 조건 때문에 **우리 서비스의 데이터도 같은 조건을 따를 수 있습니다.** 상업 여부에 따라 법률 검토가 필요합니다. (법률 자문은 아닙니다.)
  - **추천**: 사전 API의 뜻·예문을 DB에 복사하지 않고, 우리가 직접 작성합니다. 사전 API는 "검수 참고용"으로만 씁니다.
  - 아이 화면에서 실시간 호출하지 않습니다. 호출 제한과 장애 위험을 피할 수 있습니다.

### 10-1. 경기도교육청 PDF 확인 결과
- 해당 PDF는 **텍스트 없이 이미지로만 되어 있어** 내용과 이용 조건을 읽지 못했습니다. 문서 제목, 단어 수, 공공누리 유형도 확인되지 않았습니다.
- 대체 자료로 쓰려면 다음을 확인해야 합니다.
  1. goe.go.kr 게시판의 원래 글에서 **공공누리(KOGL) 유형 표시**가 있는지 확인
  2. 텍스트로 된 파일(또는 단어 목록 엑셀)을 받을 수 있는지 확인
- 공공누리 제1유형(출처표시) 이상이면 출처를 표시하고 사용할 수 있지만, **유형 표시가 없으면 사용할 수 없습니다.**

### 10-2. 발음 API 라이선스 주의
- "무료 API"라는 것과 "데이터를 저장해도 된다"는 것은 다릅니다.
- 앞서 확인한 Free Dictionary API는 **CC BY-SA 4.0**이므로, 발음 데이터를 우리 DB에 저장하면 **출처 표시와 같은 조건(ShareAlike) 적용을 검토해야 합니다.** 이것이 "라이선스 문제가 없다"는 판단과 다른 부분입니다.
- 발음 데이터를 저장하지 않고 매번 호출하는 방식은 **호출 제한(IP당 시간당 1,000회)과 장애 위험**이 있습니다.
- **추천**: 사용할 발음 API의 이용 조건을 확인한 뒤, 상업적 저장과 재배포가 허용되는 곳을 고릅니다. 허용 여부가 불명확하면 저장 방식을 바꿉니다.
