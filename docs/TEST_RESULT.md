## 1. 자동 테스트 (Vitest)

- 결과: **4개 파일 / 22개 테스트 모두 통과**

| 파일 | 대상 | 테스트 수 | 결과 |

### 자동 테스트가 덮는 범위
- 지정 풀기 24문제, 연산별 최소 5문제 고정, 난이도 미선택 시 계획 없음
- 랜덤 풀기 24문제
- 정답 5점 경험치, 250점 단위 레벨업 준비
- 자릿수 실수 / 한 칸 차이 / 받아올림 / 받아내림 / 구구단 / 나눗셈 분류
- 틀린 문제 5개 미만이면 분석하지 않음, 같은 유형 2회 이상이면 강조
- 빈칸·4자리·음수·글자 입력 거부, 정답 일치/불일치 판정

### 자동 테스트가 덮지 않는 범위 (수동 체크리스트로 확인)
- Supabase DB 함수와 RLS 권한 (SQL 마이그레이션 적용 결과)
- 서버 액션 (승인, MFA, 아이 초기화, 레벨 저장 등)
- 화면 동작, 소리, 팝업, 반응형 레이아웃
- 영어 퀴즈 예문 선택, 외부 API(발음, IPA) 응답

이 항목은 [TEST_CHECKLIST.md](TEST_CHECKLIST.md)에서 직접 확인합니다.
